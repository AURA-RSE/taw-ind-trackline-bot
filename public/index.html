Try it on WhatsApp
  1. Send any demo tracking number to the TrackLine test number.
  2. Tap Report a problem or Talk to a person, or type e.g. "TL20481738 never arrived".
  3. Exceptions (delayed 48h+, 2 failed attempts, held, damaged) open a ticket automatically and alert the ops team.

The voice line (Vapi) uses the same tools: lookup_shipment and report_problem, plus transfer to a person.
